# Внешние CTF-задачи и архивы

Проверено 26 сентября 2026 года для расширения офлайн-проверок `ico-toolkit`. Ищутся именно задания и их артефакты, а не только решения. Размеры репозиториев — поле GitHub `size` в KiB, округлённое; это ориентир по репозиторию, не точный размер ZIP. Между каталогами есть дубли, поэтому их числа нельзя складывать как количество уникальных задач.

## Полные архивы отдельных соревнований

- [DownUnderCTF](https://github.com/DownUnderCTF) — официальные папки с файлами и write-up’ами за 2020 и 2022–2025 годы. Проверены категории crypto, forensics/DFIR, pwn, reverse, web, misc и OSINT; в разных годах также есть blockchain, cloud, hardware и AI. GitHub сообщает суммарно около 1,12 GiB для пяти файловых архивов 2020, 2022–2025; каждый год примерно 53–348 MiB. 2021 в описании репозитория обозначен как write-up’ы, поэтому не включён в файловый итог. Общая лицензия для этих наборов не указана.
- [SekaiCTF](https://github.com/project-sekai-ctf) — официальные репозитории 2022–2026, с исходниками и write-up’ами; категории охватывают crypto, forensics, pwn, reverse, web, misc, PPC и blockchains. Их суммарный GitHub-размер около 1,8 GiB; 2026-й архив сам по себе около 1 GiB. Код отмечен AGPL-3.0, а нетекстовые материалы — CC BY-NC-SA 4.0, то есть с ограничением на коммерческое использование. В 2023 есть git submodule.
- [CSAW CTF, репозитории OSIRIS Lab](https://github.com/orgs/osirislab/repositories?q=CSAW-CTF) — найденные квалификации и финалы 2013–2025 годов. Есть crypto, forensics, pwn, reverse, web, misc, OSINT и другие категории. Размер сильно разнится: от нескольких MiB до сотен MiB на год/этап. У большинства старых наборов общей лицензии не видно; CSAW 2025 Finals Public помечен Apache-2.0.
- [LA CTF archive](https://github.com/uclaacm/lactf-archive) — папки 2023–2026 годов, около 279 MiB, лицензия репозитория MIT. Внутри реальные задания по crypto, pwn, reverse, web и misc; некоторые файлы подключены submodule’ами, так что для полного дерева нужна рекурсивная загрузка.
- [DownUnderCTF 2025](https://github.com/DownUnderCTF/Challenges_2025_Public), [SekaiCTF 2026](https://github.com/project-sekai-ctf/sekaictf-2026) и [CSAW 2025 Finals](https://github.com/osirislab/CSAW-CTF-2025-Finals-Public) — удобные отдельные современные срезы для проверки, если не хочется сразу брать многолетние архивы.
- [ImaginaryCTF 2022](https://github.com/ImaginaryCTF/ImaginaryCTF-2022-Challenges) — небольшой отдельный набор с папками Crypto, Forensics, Misc, Pwn, Reversing и Web; полезен как дополнительный срез, лицензия репозитория не указана.

## Узкие и онлайн-источники

- [j00ru/ctf-tasks](https://github.com/j00ru/ctf-tasks) — компактный архив реальных задач Dragon CTF и CONFidence CTF 2014–2021, в основном exploitation и reverse engineering, с исходным описанием и exploit/solution материалами; в репозитории есть Apache-2.0 LICENSE.
- [CTF-Archives organization](https://github.com/CTF-Archives) — 134 публичных репозитория; среди них есть архивы региональных соревнований и вложений. Примеры: [NCO 2026 Quals](https://github.com/CTF-Archives/2026-NCO-Quals), [NCO 2026 Final](https://github.com/CTF-Archives/2026-NCO-Final), [CISCN/CCB 2024](https://github.com/CTF-Archives/2024-CCB-CISCN-Quals). Репозитории неоднородны: часть маленькая или неполная, большинство без явной лицензии; каждый набор проверять отдельно.
- [CryptoHack CTF Archive](https://cryptohack.org/challenges/ctf-archive/) — специализированный источник криптографических задач прошлых соревнований, но это онлайн-практика, а не единый проверенный офлайн-пакет.
- [picoGym](https://play.picoctf.org/practice) — много задач по разным категориям через веб-платформу; полного официального офлайн-архива файлов в организации picoCTF не нашёл. Репозиторий [picoCTF/picoCTF](https://github.com/picoCTF/picoCTF) — устаревшая платформа 2019 года, не архив заданий; `picoCTF-2019-example-problems` содержит примеры, а не весь picoGym.
- [MemLabs](https://github.com/stuxnet999/MemLabs) — семь CTF-подобных memory-forensics лаб, MIT. Сам Git-репозиторий около 562 KiB; образы памяти не лежат рядом в проверенной папке Lab 1, поэтому это не готовый единый набор файлов для сканера.
- [archive.ooo](https://archive.ooo/) — интерактивный архив задач DEF CON CTF; подходит для ручной тренировки, но не заменяет локальный пакет challenge-файлов.

## Что загружать для тестов сканера

1. Начать с Hackropole: он даёт 627 проверенных страниц и прямые ссылки на артефакты семи категорий.
2. Добавить pwn.college CTF Archive как структурированный локальный набор на 703 записи. Для каждой задачи отдельно фиксировать, нужен ли Docker/сервис.
3. Для широкого разнообразия брать нужные годы и категории через `ctf-replay` из Sajjadium, а не скачивать весь репозиторий.
4. Для современных официальных заданий выбрать по одному году из Google CTF, DownUnderCTF, SekaiCTF, CSAW и LACTF.
5. Перед слепым прогоном исключить `writeup`, `solution`, `exploit`, `flag`, `answer` и исходники/генераторы, когда цель — проверить только входные артефакты. Иначе это будет поиск уже опубликованного решения, а не тест solver’а.

Не все задачи можно решить сканированием одного локального файла: web/pwn и часть crypto требуют поднять сервис, взаимодействовать с ним или собрать окружение. Для отчёта по качеству разделять `offline-file`, `local-service`, `online-only`, `writeup/reference` и подтверждённые результаты. Количество файлов или найденных строк `flag{...}` само по себе не является числом решённых задач.
