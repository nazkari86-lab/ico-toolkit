# ico-scan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Build a local `ico-scan` CLI that accepts one or more files/directories, classifies them, runs safe offline CTF analyzers in deterministic order, follows bounded extracted artifacts, and reports flag-shaped evidence with provenance.

**Architecture:** A standard-library Python engine owns the queue, classifier, bounded subprocess runner, matcher, extraction sandbox, and JSON/text report. Tool profiles are data-driven and selected from MIME/signature/extension hints. A tiny executable wrapper exposes the command through the existing toolkit `PATH`.

**Tech Stack:** Python 3.14 standard library, installed macOS CLI tools (`file`, `strings`, `exiftool`, `binwalk`, `zsteg`, `pngcheck`, `steghide`, `7zz`, `qpdf`, `tshark`, `r2`, `ffprobe`), JSON, and `unittest` from the standard library.

**Spec:** `$ICO_TOOLKIT_ROOT/docs/superpowers/specs/2026-09-23-ico-scan-design.md`

## Global Constraints

- Input is local files or directories supplied by the user.
- No HTTP requests, port scans, platform interaction, flag submission, password dictionaries, or flag guessing are performed.
- External tools are invoked with argument arrays, never through a shell.
- Extracted binaries are inspected as bytes and never executed.
- Password-protected stego containers are inspected for metadata only; no wordlist cracking or password guessing.
- Every match is marked `candidate` until an original checker or authorized service confirms it.
- Missing tools and tool failures are recorded as non-fatal events.
- StudyLab and unrelated projects remain untouched.

**Files:**
- Create: `ico_scan_core.py`
- Create: `tests/test_ico_scan_core.py`

**Interfaces:**
- `Artifact(path: pathlib.Path, depth: int, parent: str | None)` stores a queue item.
- `Classification(mime: str, description: str, kind: str, extension: str)` is JSON-serializable.
- `CommandRunner.run(args: list[str], *, cwd: pathlib.Path, timeout: float, log_name: str) -> CommandResult` runs one allowlisted executable without a shell, captures bounded UTF-8 text, writes a log, and records timeout/exit status.
- `classify(path: pathlib.Path, runner: CommandRunner) -> Classification` uses `file --brief --mime-type` and `file --brief`, then extension/magic hints.
- `FlagMatcher(patterns: list[str]).scan(text: str, *, source: str, analyzer: str) -> list[dict]` returns candidate records with exact value, line number, source, and state `candidate`.
- `sha256_file(path: pathlib.Path, limit: int | None = None) -> str` computes stable de-duplication hashes.

### Task 2: Tool profiles and bounded extraction queue

**Files:**
- Create: `ico_scan_profiles.py`
- Modify: `ico_scan_core.py`
- Create: `tests/test_ico_scan_profiles.py`

**Interfaces:**
- `ToolProfile(name: str, kinds: frozenset[str], executable: str, args: Callable[[Path], list[str]], timeout: float = 30.0)` describes one read-only analyzer.
- `profiles_for(classification: Classification) -> list[ToolProfile]` returns universal tools first, then class-specific tools in deterministic order.
- `ArchiveExtractor.extract(path: Path, classification: Classification, destination: Path) -> ExtractionResult` lists with `7zz -slt`, refuses declared expansion above the byte/file limits, extracts only inside the run directory, and returns discovered regular files.
- `is_archive(classification: Classification) -> bool` covers ZIP/7z/RAR/TAR/GZIP/ISO/document containers using MIME and description hints.

```python
def test_png_profile_includes_zsteg_and_pngcheck():
    names = [p.name for p in profiles_for(Classification("image/png", "PNG image", "png", ".png"))]
    assert names.index("zsteg") < names.index("pngcheck")

def test_archive_expansion_limit_refuses_large_listing(tmp_path):
    archive = tmp_path / "sample.zip"
    archive.write_bytes(b"invalid archive bytes")
    classification = Classification("application/zip", "Zip archive data", "archive", ".zip")
    runner = FakeRunner({"7zz -slt": "Path = x\nSize = 999999999\n"})
    result = ArchiveExtractor(runner, max_bytes=1024).extract(archive, classification, tmp_path / "out")
    assert result.refused_reason == "declared expansion exceeds byte limit"
```
