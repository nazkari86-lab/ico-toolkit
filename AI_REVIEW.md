# Как передать ICO Toolkit в Claude или другой ИИ

Репозиторий публичный. Некоторые ИИ могут открывать только URL, явно присланные
пользователем, а их среда выполнения не имеет доступа к сети. В таком случае
ссылка на главную страницу GitHub не предоставляет доступ ко всем исходникам.

## Полный пакет собственного кода

В каталоге репозитория выполните:

```sh
python3 scripts/package_review.py --out review-exports/claude
```

Для повторного экспорта выберите новый пустой каталог. Экспорт берёт
зафиксированный коммит `HEAD`; незакоммиченные изменения не включаются.
Можно указать другой коммит через `--revision`.

Загрузите в чат `review-exports/claude/ico-src.zip`. Он содержит собственные
исходники, скрипты, тесты, документацию и текстовые launcher-скрипты. Вместе с
ними включены инструкция для ревью, SHA-256 каждого файла, номер коммита и
список содержимого `scripts/`, `tests/`, `docs/`, `benchmarks/`.

Для первого прохода доступны `ico-priority.zip` и `ico-priority.txt`: шесть
запрошенных файлов в архиве или одном текстовом вложении. Если чат не умеет
читать ZIP, приложите TXT либо извлеките ZIP и приложите отдельные `.py`.

В архивы не входят виртуальные окружения, локальные отчёты, пользовательские
файлы вне коммита, `vendor/`, CyberChef, модели, нативные бинарники и данные
бенчмарков. Это пакет для чтения кода, а не автономный дистрибутив инструмента.
Исходные файлы в основном репозитории доступны в полном составе.

## Онлайн-ссылки на текущую версию main

Эти прямые адреса можно **вставить в сообщение самому ИИ**, если его fetch
разрешает только явно предоставленные пользователем URL:

- https://raw.githubusercontent.com/nazkari86-lab/ico-toolkit/main/ico_solver_engine.py
- https://raw.githubusercontent.com/nazkari86-lab/ico-toolkit/main/ico_solve.py
- https://raw.githubusercontent.com/nazkari86-lab/ico-toolkit/main/ico_universal_registry.py
- https://raw.githubusercontent.com/nazkari86-lab/ico-toolkit/main/ico_task_solvers.py
- https://raw.githubusercontent.com/nazkari86-lab/ico-toolkit/main/ico_prompt_solvers.py
- https://raw.githubusercontent.com/nazkari86-lab/ico-toolkit/main/TOOL_CATALOG.md

Ссылки выше меняются вместе с `main`. При ревью экспортированного архива
используйте ссылки из его `REVIEW_FIRST.md`: упаковщик подставляет точный
коммит вместо `main`, поэтому онлайн-файлы совпадают со снимком. Коммит должен
быть опубликован в этом репозитории; для локального коммита используйте вложения.

Если доступ к этим адресам также закрыт, используйте вложения выше: изменения
репозитория не могут включить сеть в чужой песочнице.

Проверка уже полученной критики по коду и сохранённым результатам:
[факты, ограничения и приоритеты улучшений](docs/research/2026-09-28-solver-review-evidence.md).

## Где находится handoff для GPT-4.1

Генерация prompt и ZIP находится в `ico_solve.py`, функция
`_write_gpt_handoffs`. `ico_prompt_solvers.py` содержит решатели задач по их
условиям. Для анализа передачи производных файлов также нужны
`ico_scan.py`, `ico_solver_engine.py` и `ico_tool_adapters.py`; все они есть
в полном архиве `ico-src.zip`.
